# G3 招募材料（G3.1）

## 找谁

5–10 位**真实在做合成、修图或调色**的人。配额尽量满足：

| 条件 | 至少 |
|---|---|
| Photoshop 用了 3 年以上 | 3 人 |
| 用过 Photopea、Affinity、GIMP 等替代品 | 2 人 |
| 平时用 Windows | 2 人 |
| 平时用 Safari（Mac 默认浏览器） | 1 人 |
| 用过桌面版 Compositor | 有就邀请 1 人 |

**不找**：从没做过修图的人；做 UI 设计、平时只用 Figma 的人（不是这次要验证的人群）；项目组成员和他们的亲友。

## 筛选问卷（报名时填，1 分钟）

1. 你平时做合成、修图或调色吗？ ○ 几乎每天 ○ 每周几次 ○ 每月几次 ○ 很少 / 不做（→ 不邀请）
2. 你用 Photoshop 或类似软件多久了？ ○ 不到 1 年 ○ 1–3 年 ○ 3–5 年 ○ 5 年以上
3. 你还用过哪些修图工具？（多选）□ Photopea □ Affinity Photo □ GIMP □ Pixelmator □ 桌面版 Compositor □ 手机 App □ 其他
4. 你平时用什么电脑和浏览器？ ○ Mac + Chrome ○ Mac + Safari ○ Windows + Chrome / Edge ○ 其他
5. 下周哪些时段方便线上 45 分钟？（需要能共享屏幕）

> 招 5–10 位做合成 / 修图的朋友，帮忙试一个网页版 PS 替代工具 🙏

>
> ✅ 平时会用 PS 或类似软件做合成、修图、调色
> ✅ 有电脑，能开视频会议共享屏幕
> 🎁 感谢礼：（填上你的感谢礼）
>
> 感兴趣请私信，或填这份 1 分钟的报名表：（链接）

**微信群 / 朋友圈**

> 想请做设计 / 修图的朋友帮个忙：我在做一个浏览器里用的合成工具（可以理解为网页版的简化 PS），想找几位真实用户试一次。
> 线上 45 分钟，用它换一张照片的天空，边做边说感受。我们测的是工具不是你，越挑刺越好。有兴趣的私我 🙌
