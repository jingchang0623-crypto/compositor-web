# ArtPS · G3 用户验证：计划

**要验证的假设（H2）**：想离开 Photoshop 的人，愿意用"打开网页就能用"的工具做合成。

**怎么验证**：请 5–10 位真实的 Photoshop / 桌面版 Compositor 用户，用 ArtPS 线上版完成一个完整的小合成——**换天空 + 调色 + 导出**，
观察能不能独立做完，再问值不值得用。

| 目标 | 通过线 | 从哪来 |
|---|---|---|
| G3.1 招募 | 5–10 人名单确定 | [招募材料](recruitment.md) |
| G3.2 独立完成 | ≥ 70% 的人独立完成三个必做任务 | 观察记录（没有主持人时用问卷自评） |
| G3.3 三色灯 | 见下方判定规则 | 问卷"对你来说，ArtPS 是" |

## 判定规则

汇总页（`?g3=results`）按下面的规则自动给出结论，代码在 `src/g3/scoring.ts`，有单元测试。

- **🟢 绿灯 → 进入 G4**：独立完成率 ≥ 70%，并且选绿灯的人 ≥ 一半。G4 的顺序按问卷里"最先要补的功能"投票排。
- **🔴 红灯 → 重新评估 H2**：独立完成率 < 50%，或者选红灯的人 ≥ 40%。先搞清楚是"这个方向不对"还是"这版太难用"，再决定继续不继续。
- **🟡 黄灯 → 换切口再验证**：介于两者之间。先修最卡人的一两处，或者换一个更窄的场景（比如只做"换天空"这一件事），换一批新用户再测。
- 少于 5 人不下结论。

同时看、但不作为关卡的指标：SUS（行业平均约 68）、NPS、各任务的难度评分（SEQ）、每月愿付金额。

**独立完成的定义**：三个必做任务（换天空、调色、导出）都完成，主持人最多只给过 1 级帮助（中性追问，比如"你现在想做什么？"）。
帮助等级见[主持人手册](moderator-guide.md#帮助等级)。

## 测试包（都在线上，静态页面，无需后端）

线上地址：https://jingchang0623-crypto.github.io/compositor-web/

| 页面 | 给谁 | 地址 |
|---|---|---|
| 任务卡 | 参与者 | `?g3=task&p=P01`（把 P01 换成各自的编号） |
| 问卷 | 参与者 | `?g3=survey&p=P01`（任务卡末尾有链接） |
| 观察记录 | 主持人 | `?g3=observe&p=P01` |
| 汇总 | 主持人 | `?g3=results` |

- 任务卡里的"打开编辑器和街景"会直接打开起始项目；晚霞图片 `sky.jpg` 由参与者自己放进去（这一步本身也在测导入）。
- 问卷提交后下载 `P01-survey.json`，观察记录导出 `P01-observation.json`。把所有文件拖进汇总页，就能看到结论，
  并可"复制 Markdown 摘要"贴进 [GOALS.md](../../GOALS.md)。
- 问卷题目：[questionnaire.md](questionnaire.md)（由 `src/g3/questions.ts` 生成，改题目改那个文件，再 `npm run g3:doc`）。
- 素材是程序生成的，没有版权问题：`npm run g3:materials` 重新生成到 `public/g3/`。

## 形式

- **推荐：远程主持，每人 45 分钟。** 视频会议 + 参与者共享屏幕，主持人一边看一边填观察记录。
  开场 5 分钟 → 任务 25 分钟 → 访谈 5 分钟 → 问卷 5 分钟 → 收尾 5 分钟。
- **补充：无主持。** 只发任务卡链接，参与者自己做完填问卷。数据更粗（只有自评），适合在主持场次之外多收几份。

## 排期（约一周）

| 天 | 做什么 |
|---|---|
| 第 1–2 天 | 按[招募材料](recruitment.md)发帖、筛选、约时间；先找一位同事跑一场预测试，修掉任务卡里说不清的地方 |
| 第 3–6 天 | 每天 2–3 场；每场结束当天收齐 JPEG、`-survey.json`、`-observation.json` |
| 第 7 天 | 汇总页出结论，写进 GOALS.md 的进度日志，决定进 G4、换切口还是重新评估 |

## 数据与隐私

- 问卷和观察记录都**不收集姓名和联系方式**，只用编号（P01…）。编号和人的对应表由主持人另外保存。
- 问卷会附带浏览器、系统、屏幕尺寸和显卡名称，用来区分"设备问题"和"设计问题"，页面上有说明。
- 结果文件只存在参与者和主持人的电脑上；汇总页在本地读取，不上传。
- 录屏需要参与者口头同意（开场白里有这句），录像只用于回看，结束后删除。
