# G3 主持人手册

每场 45 分钟，远程视频 + 参与者共享屏幕。主持人的任务是**看和记**，不是教。参与者卡住的地方，正是我们要找的东西。

## 场前 10 分钟

- [ ] 给参与者分配编号（P01、P02…），在自己的对应表里记下编号和人
- [ ] 准备好任务卡链接：`https://jingchang0623-crypto.github.io/compositor-web/?g3=task&p=P0X`
- [ ] 打开观察记录：`?g3=observe&p=P0X`，填好日期和设备
- [ ] 提醒参与者用电脑、最新版 Chrome / Edge / Safari，安排好能共享屏幕的会议
- [ ] 自己先打开一次任务卡，确认页面和素材能加载

## 开场（5 分钟，照着说）

> 谢谢你来帮忙。今天请你试用一个还在早期的网页版合成工具，大概 25 分钟做几件小事，最后填一份 5 分钟的问卷。
>
> 先说清楚：**我们测的是这个工具，不是你**。你卡住、觉得别扭的地方，对我们最有用，不用觉得不好意思。
> 它还缺不少 Photoshop 的功能，这是正常的。
>
> 做的时候请尽量**边做边说**：你在找什么、以为会发生什么、结果和预期一不一样。我会尽量不插话；
> 你问我问题时，我可能会反问"你觉得呢？"，因为我们想看你一个人用的时候会怎样。
>
> 为了事后回看，我想录一下屏幕，录像只给项目组看，用完删除。可以吗？（得到同意再录）

热身（2 分钟）：
- 你平时用什么软件做合成或修图？最近一次做的是什么？
- 你换过天空吗？一般怎么做？（听对方习惯的做法，不评价）

## 任务（25 分钟）

把任务卡链接发给参与者，请对方读一遍，然后开始。**每项任务开始时按观察记录里的"计时"，结束时再按一次。**

| 任务 | 给参与者的目标（任务卡原文） | 算完成 |
|---|---|---|
| T1 换天空 | 把灰蒙蒙的天空换成晚霞，楼、天线和树留在天空前面 | 整片天空换掉，楼顶边缘没被盖住（几像素误差可以，楼缝里的树冠不强求） |
| T2 调色 | 调整街景颜色和明暗，看起来像被晚霞照着 | 看得出为了和天空协调做了变暖或明暗调整 |
| T3 导出 | 导出一张 JPEG 发给主持人 | 拿到 JPEG 文件 |
| T4 保存（可选） | 把项目保存下来 | 得到 .comp 文件夹或 .comp.zip |

T1 做到 20 分钟还没完成：请对方先跳到 T2、T3，T1 记为"没完成"。整场任务部分最多 30 分钟。

### 帮助等级

对方主动求助、或者卡住超过 3 分钟时，按顺序升级，**每次升级都在观察记录里选上**：

| 等级 | 说什么 | 算独立完成吗 |
|---|---|---|
| 0 | 不说话 | 算 |
| 1 | 中性追问："你现在想做什么？""你在找什么？" | 算 |
| 2 | 给提示：指一个区域或功能，"看看图层面板下面那排按钮" | **不算** |
| 3 | 直接告诉或演示怎么做 | **不算** |

1 级之后再卡 2 分钟，才升到 2 级。宁可等，别抢着帮。

### 看什么（记进"关键事件"，会自动带时间）

- 怎么把 sky.jpg 放进来：拖进窗口？菜单"打开图片"？找了多久？
- 放进来之后，想没想到要移动或缩放它；找没找到移动工具的手柄
- 怎么处理"楼要在天空前面"：蒙版？删除像素？调整图层顺序？**有没有先找魔棒或套索**（这是我们最想知道的缺口之一）
- 选区：会不会用 Shift 加选，选了几个矩形
- 调色用了什么：曲线、色相 / 饱和度、色阶，还是改不透明度；知不知道调整图层会影响下面所有图层
- 导出：在菜单里找了多久；Safari 用户会下载一个文件，注意是否困惑
- 撤销：用了几次 ⌘Z；有没有因为撤销不了而重来
- 任何"咦？""它怎么……"之类的话，原样记在"原话"里

### 可行路径（只给主持人参考，不要告诉参与者）

现在没有魔棒、选择主体和套索，换天空要靠选框或画笔：

- **路径 A（最常见）**：晚霞放在街景上面并移到顶部 → 在街景上用选框框出天空（先框楼顶以上的大块，再按住 Shift 逐段加选楼与楼之间的空隙）
  → 选中晚霞图层 → 点"添加蒙版"（有选区时，蒙版只显示选区里的部分）
- **路径 B**：同样框出天空 → 在街景图层上按 ⌫ 删掉天空像素 → 把晚霞拖到街景下面
- **路径 C**：给晚霞加蒙版，用黑色画笔把楼的部分涂掉（慢，但 PS 老用户可能这么做）
- 调色：新建"曲线"或"色相/饱和度"调整图层。路径 A 里把调整图层放在街景和晚霞之间，就只影响街景；路径 B 里调整图层会同时影响露出来的天空（目前还没有剪贴蒙版），调得克制一点同样算完成
- 导出：菜单"文件 → 导出 JPEG"（⇧⌥⌘S）

**预期**：T1 最难、最慢。如果大多数人卡在"选天空"，说明自动选区（魔棒 / 选择主体）是 G4 的第一优先级，这本身就是一个有效结论。

## 访谈（5 分钟，任务后、问卷前）

1. 整个过程里，哪一刻最让你想放弃？当时你期望它怎么做？
2. 哪一刻让你觉得"这个还挺顺手"？
3. 如果明天起你的电脑上用不了 Photoshop，你会用它完成类似的活吗？还差什么？
4. 你会在什么场合想到用网页版，而不是打开桌面软件？

然后把问卷链接发过去（任务卡末尾就有），请对方填完、把下载的 `P0X-survey.json` 和导出的 JPEG 一起发给你。

- [ ] 道谢，发放感谢礼

## 已知限制（参与者问到时如实回答，不主动说）

- 没有魔棒、选择主体、套索、裁剪、文字、图层样式、渐变、修复画笔
- 画笔没有数位板压感
- Safari / Firefox 的"保存"是下载 zip；Chrome / Edge 可以直接写回文件夹
- 图片单边超过显卡上限（通常 16384 像素）会被缩小导入

## 故障处理

| 现象 | 处理 |
|---|---|
| 页面提示"WebGL2 不可用"或白屏 | 换最新版 Chrome；公司电脑可能关了硬件加速 |
| 页面卡死或刷新丢了 | 重新打开编辑器，欢迎页的"未保存的工作"里能恢复（改动后 3 秒自动保存） |
| 打开编辑器的链接没带出街景 | 在任务卡点"街景原图"下载 street.jpg，拖进编辑器 |
| 问卷提交后没看到文件 | 用"复制结果"把内容粘贴到聊天里发过来 |

记下所有故障（算"关键事件"），它们也是结果的一部分。
